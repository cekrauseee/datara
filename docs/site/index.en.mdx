## Choose a guide

Datara's current web application explores geographic boundaries in Brazil and the United States. The separate election API queries immutable published snapshots. Election results are not yet integrated into the map interface.

- [Explore the map](/product/exploration)
- [Make your first API request](/api/first-request)
- [Develop and operate Datara](/development/setup)

## Data coverage

The map uses simplified visualization boundaries. The API currently has a limited official election pilot; its national acquisition command does not prove completed nationwide coverage. Read each publication's coverage before interpreting missing observations.

## Reading preferences

The documentation offers Light, Dark and System themes. System follows your device preference and is the default on a first visit; an existing theme choice is preserved. Changing languages or opening another guide keeps your choice.
