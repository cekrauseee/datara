## Escolha um guia

A aplicação web atual do Datara explora limites geográficos do Brasil e dos Estados Unidos. A API eleitoral separada consulta publicações imutáveis. Os resultados eleitorais ainda não estão integrados à interface do mapa.

- [Explore o mapa](/product/exploration)
- [Faça a primeira requisição à API](/api/first-request)
- [Desenvolva e opere o Datara](/development/setup)

## Cobertura dos dados

O mapa usa limites simplificados para visualização. A API tem um piloto eleitoral oficial limitado; a existência do comando de aquisição nacional não comprova cobertura nacional concluída. Consulte a cobertura de cada publicação antes de interpretar observações ausentes.

## Preferências de leitura

A documentação oferece os temas Claro, Escuro e Sistema. Sistema segue a preferência do dispositivo e é o padrão na primeira visita; uma escolha de tema existente é preservada. Trocar de idioma ou abrir outro guia mantém sua escolha.
